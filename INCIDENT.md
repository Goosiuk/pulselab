# Остановка и восстановление сервиса

7 ноября 2026 года, 00:48 по Москве. Локальная проверка сервиса в Docker.

## Условия

- Образ `pulselab:local`, Linux/arm64, Python 3.12.16.
- Контейнер `pulselab-demo`, приложение работает от UID 10001.
- URL: `http://127.0.0.1:8088/health`.
- Монитор работает на Mac, Python 3.12.3.
- В каждой фазе две пробы, интервал 0.1 секунды, таймаут сетевой операции 0.5 секунды.

При остановке сервиса монитор продолжал работать и записывал ошибки в JSONL. Состояние контейнера подтвердило остановку процесса: `Pid=0`, `Running=false`, `OOMKilled=false`. После запуска того же контейнера по тому же адресу снова получены успешные ответы. Пересборка образа для восстановления не потребовалась.

Это функциональная проверка с намеренно вызванным отказом. Проценты относятся к двум пробам каждой фазы, а не к доступности за месяц. Время между отдельными пробами не наблюдалось непрерывно.

Следующая доработка — добавить UTC-метку в каждую запись монитора. Сейчас восстановление выполняется отдельной командой `docker start`, а не самим монитором.
